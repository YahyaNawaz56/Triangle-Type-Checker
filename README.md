# Triangle Type Checker
This project determines the type of a triangle (Acute, Right, or Obtuse; Isosceles or Scalene)
based on three side lengths entered by the user.

## Features
- Validates triangle sides
- Identifies angle type (Acute, Right, Obtuse)
- Identifies side type (Scalene, Isosceles, Equilateral)

## How to Run
python triangle_checker.py
